## How to use this site

Platform workflows are located on the left. You can click between them to see how the entire workflow differs across platforms. If you want to see how a specific step changes (or doesn't!) between platforms, see the [Tags](/tags/) tab on the masthead.

### Tags

Each workflow can be broken down into various steps and concepts. If you want to see how these steps vary across workflows, the Tags tab allows you to sort and view steps and concepts by groups.

***For more information on the steps and concepts associated with this workflow, see the [Conceptual Guide](/guide/)***
